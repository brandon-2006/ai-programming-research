Research Question

How can AI coding assistants help beginner programmers develop software while maintaining code quality and understanding of programming concepts?

Audience: Computer science students and beginner programmers.

The goal of this research is to understand both the advantages and limitations of AI-assisted programming.

Research and Evidence

Potential Benefits of AI

A 2023 controlled experiment involving GitHub Copilot found that developers with access to the AI assistant completed a programming task 55.8% faster than the control group.

This suggests that AI tools can help developers complete certain programming tasks more efficiently.

Limitations of AI

A 2025 METR study examined experienced open-source developers completing real tasks in familiar repositories. Developers using AI tools took 19% longer on average in that particular study.

This demonstrates that AI does not automatically make every programming task faster. Reviewing, correcting and integrating generated code can require additional effort.

2026 Research Update

In February 2026, METR published an update explaining that its newer experiment faced limitations because developers increasingly preferred working with AI tools. The researchers cautioned that their newer data could not reliably measure the current productivity impact of AI. This reinforces the importance of considering the date and limitations of research when evaluating AI tools.

Facts, Interpretations, and Assumptions

Facts

  • The 2023 GitHub Copilot study found that participants completed a specific coding task 55.8% faster with AI assistance.
  • The 2025 METR study found that experienced developers took 19% longer when using AI tools in the tasks studied.
  • These studies examined different developers and programming tasks.

My Interpretations

I interpret these findings to mean that AI productivity depends on the developer's experience and the type of programming task. AI can be useful, but it does not guarantee faster development.

My Assumptions

  • Beginners may benefit from AI explanations and examples.
  • Writing tests before using AI may help identify incorrect generated code.
  • Understanding the code is more important than simply generating it quickly.

These assumptions still need to be investigated through my own programming experiments.

Comparing Programming Approaches

Approach 1: AI-First Programming

The developer asks AI to generate most of the code before testing or reviewing it.

Potential advantage: Faster initial development.

Potential disadvantage: Errors and misunderstandings may go unnoticed.

Approach 2: Test-First AI-Assisted Programming

The developer first defines requirements and tests. AI is then used to help implement the functionality. The developer reviews the code and runs the tests.

Potential advantage: Better opportunities to identify incorrect behavior.

Potential disadvantage: Requires more planning before implementation.

My Initial Interpretation

I believe the second approach is more appropriate for beginner programmers because it encourages understanding, verification and problem-solving instead of blindly accepting generated code.

Planned Experiment

  • Compare the amount of time needed.
  • Check whether the generated code passes tests.
